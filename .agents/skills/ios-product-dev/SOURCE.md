# Source and attribution

This is original repository-local guidance for Companion's native iOS client. It is informed by
the local iOS contributor guidance, product contract, architecture/design documents, and the
existing SwiftUI implementation.

Platform references used for terminology and recommendations:

- Apple Human Interface Guidelines: https://developer.apple.com/design/human-interface-guidelines/
- SwiftUI documentation: https://developer.apple.com/documentation/swiftui
- Apple accessibility documentation: https://developer.apple.com/accessibility/

No Apple text or code is copied into this package, and no Apple license is redistributed. The
Companion-specific rules are project guidance and remain subordinate to the repository's
contributor instructions.
