# Source and attribution

This is original repository-local implementation guidance for the Companion SwiftUI client. It
is informed by the local iOS contributor guidance, the existing SwiftUI and CompanionKit code,
and Apple's public platform documentation:

- SwiftUI documentation: https://developer.apple.com/documentation/swiftui
- Swift concurrency documentation: https://developer.apple.com/documentation/swift/concurrency
- Apple accessibility documentation: https://developer.apple.com/accessibility/

No Apple text or code is copied into this package, and no Apple license is redistributed. The
Companion-specific rules remain subordinate to repository contributor instructions.
