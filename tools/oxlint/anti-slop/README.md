# Vendored anti-slop plugin

This directory contains the generic rules from
[`dmmulroy/anti-slop`](https://github.com/dmmulroy/anti-slop), vendored from commit
`6d538555cb151d4121ed51a27db81890eacf8ae9`.

The files are maintained as project-owned source. Review upstream changes before copying a newer
revision, keep `oxlint` and `@oxlint/plugins` on matching versions, and retain the bundled MIT
license when updating this directory.
